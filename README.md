# Pickpl (픽플)

특별한 장소(PLACE)에서 찍은 사진(PICTURE)을 공유하고,

다른 사람이 올린 사진(PICTURE)을 모아볼 수 있는(PICK) 공간을 만들고자 하였습니다.

이러한 특징들을 잘 전달할 수 있는 단어들을 조합하여 **“PICKPL”** 이 탄생되었습니다.

## 개발

* 개발 환경
  * Windows
  * MacOs

* 개발 도구 & DB
  * eclipse
  * Oracle

* 개발 언어
  * Java
  * HTML, CSS, JavaScript, jQuery
  * JSP & Servlet

* 사용 API 및 플러그인
  * 카카오맵 API
  * 카카오 메시지 API
  * 도로명주소 주소 검색 API
  * 국가공간정보포털 오픈API
  * WebSocket API
  * slick.js (carousel, 이미지 슬라이드) 
  * sweetAlert2.js (팝업)
